# Software developer from Ghana building digital products around real-world problems.

I’m **Kryptonian**, a Ghanaian software developer and product builder with a background in **Mathematics and Computer Science**.

I enjoy taking an operational problem, understanding how people actually work, and turning that workflow into practical software.

My work sits around **business systems, SaaS, web applications, and Ghanaian-first digital products**.

## What I build

- **Business systems** for administration, operations, reporting and structured workflows
- **SaaS products** with authentication, roles, data management and multi-user workflows
- **Web applications** focused on useful user experiences rather than technical demos
- **Ghanaian-first products** designed around local workflows, constraints and opportunities

### WedQR Ghana
**A browser-based digital wedding programme generator with QR sharing.**

Couples can create a wedding programme, preview it in real time, generate a QR code and share it with guests without requiring a native app or traditional backend.

**Stack:** React · TypeScript · Vite · Tailwind CSS · React Hook Form · Zod · QR generation · URL compression

[View repository](https://github.com/Kryptonian-code/WedQR-Ghana)

## How I approach software

**Problem → Understand the workflow → Design the system → Build the right features → Test real use cases → Simplify and improve**

I’m less interested in software that only looks impressive in a demo and more interested in software that remains useful after the demo is over.

## Building from Ghana 🇬🇭

I build with the Ghanaian context in mind.

That means paying attention to local business processes, affordability, connectivity, digital literacy and the difference between how software is supposed to be used and how people actually use it.
